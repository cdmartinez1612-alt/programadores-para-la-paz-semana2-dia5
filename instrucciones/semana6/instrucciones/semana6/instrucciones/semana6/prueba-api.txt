Al enviar una petición POST a la ruta /registro con el JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor devuelve:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto demuestra que Express recibe correctamente los datos enviados mediante req.body.
